# Algebra

Algebra is about **35% of the Math section**. Every question here is about *linear* relationships: equations, functions, and inequalities whose graphs are straight lines. Master these and you lock in a big share of your Math score.

> **Big idea:** a linear relationship changes by the same amount every step. In $y = mx + b$, $m$ is that constant rate of change (slope) and $b$ is the starting value ($y$-intercept).

## Linear equations in one variable {#ALG.LE1}

**What it tests:** solving equations like $3(2x - 5) = 2x + 9$, and recognizing when an equation has **one**, **no**, or **infinitely many** solutions.

**Strategy**

1. Distribute and combine like terms on each side.
2. Move all $x$-terms to one side and constants to the other.
3. Divide by the coefficient of $x$.

**Worked example.** Solve $4(x + 2) = x + 23$.
Distribute: $4x + 8 = x + 23$. Subtract $x$: $3x + 8 = 23$. Subtract 8: $3x = 15$, so $x = 5$.

**Number of solutions.** After simplifying to $ax + b = cx + d$:

| Situation | Result |
|---|---|
| $a \ne c$ | exactly one solution |
| $a = c$ and $b \ne d$ | **no** solution |
| $a = c$ and $b = d$ | **infinitely many** solutions |

**Traps**
- Forgetting to distribute to *every* term inside parentheses.
- Sign errors when moving a negative term across the equals sign.
- Answering the wrong quantity: if the question asks for $2x$, don't stop at $x$.

## Linear functions {#ALG.LF}

**What it tests:** reading and building $f(x) = mx + b$ from equations, tables, graphs, and word problems, and interpreting slope and intercept in context.

**Strategy**
- Slope from two points: $m = \dfrac{y_2 - y_1}{x_2 - x_1}$.
- Then find $b$ by plugging in one point.
- In context, the **slope is a rate** ("per hour", "per item") and the **intercept is a starting amount** (the value when the input is 0).

**Worked example.** $f(2) = 7$ and $f(5) = 16$. Slope $= \frac{16 - 7}{5 - 2} = 3$. Then $7 = 3(2) + b$, so $b = 1$ and $f(x) = 3x + 1$. So $f(0) = 1$.

**Traps**
- Swapping the order of subtraction in the slope formula for only the top or only the bottom.
- Mixing up "fixed fee" (intercept) and "cost per unit" (slope).

## Linear equations in two variables {#ALG.LE2}

**What it tests:** equations like $ax + by = c$, their graphs, intercepts, and parallel / perpendicular lines.

**Strategy**
- $x$-intercept: set $y = 0$. $y$-intercept: set $x = 0$.
- Slope of $ax + by = c$ is $-\dfrac{a}{b}$ (solve for $y$ if you forget).
- **Parallel** lines have equal slopes. **Perpendicular** slopes are negative reciprocals: $m$ and $-\frac{1}{m}$.

**Worked example.** Pens cost \$3 and notebooks \$8. Sam spends \$46 and buys 10 pens. Then $3(10) + 8n = 46$, so $8n = 16$ and $n = 2$ notebooks.

**Traps**
- Using $\frac{a}{b}$ instead of $-\frac{a}{b}$ for the slope.
- Forgetting to flip *and* negate for perpendicular slopes.

## Systems of two linear equations {#ALG.SYS}

**What it tests:** solving two equations together, and knowing when a system has no solution or infinitely many.

**Strategy**
- **Elimination:** add or subtract the equations (after multiplying) so one variable cancels.
- **Substitution:** solve one equation for a variable and plug it into the other.
- If the question asks for $x + y$ or $2x - y$, look for a shortcut by adding/subtracting the equations directly.

**Worked example.** $x + y = 10$ and $x - y = 4$. Add: $2x = 14$, so $x = 7$ and $y = 3$.

**Special cases.** A system has **no solution** when the lines are parallel (same slope, different intercepts) and **infinitely many** when the equations describe the same line (one is a multiple of the other).

**Traps**
- Solving for $x$ when the question asks for $y$.
- Multiplying only one side of an equation when scaling it.

## Linear inequalities {#ALG.INE}

**What it tests:** solving inequalities, word problems with limits ("at most", "at least"), and systems of inequalities.

**Strategy**
- Solve like an equation, but **flip the inequality sign when you multiply or divide by a negative number**.
- "At most" means $\le$; "at least" means $\ge$.
- For "which point is a solution", plug each point into **every** inequality.

**Worked example.** A club has at most \$80, pays a \$10 fee and \$7 per ticket. $10 + 7n \le 80$, so $n \le 10$. The club can buy at most 10 tickets.

**Traps**
- Forgetting to flip the sign after dividing by a negative.
- Rounding up when the context requires a whole number that stays within a limit (round **down** for "at most").
